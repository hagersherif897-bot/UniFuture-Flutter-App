# 🚀 UniFuture App - تطبيق جامعتي ومستقبلي

A beautiful and Flutter-based mobile application designed specially for IT and Software Engineering graduates to track their goals, study new tech tracks, and reduce post-graduation anxiety.

تطبيق هاتف ذكي متميز تم بناؤه باستخدام إطار العمل Flutter، مصمم خصيصاً لخريجي تكنولوجيا المعلومات وهندسة البرمجيات لمساعدتهم على تنظيم أهدافهم، واستكشاف المسارات التقنية المختلفة، وتقليل قلق فترة انتظار النتائج.

---

## ✨ Features | المميزات الرئيسية

- **🎯 Career Paths Explorer:** Explore the most in-demand tracks in the IT market (Mobile Dev, Web Dev, QA, Data Analysis).
- **📋 Graduate To-Do List:** Manage daily learning goals and keep track of tasks (e.g., practicing Dart, building layouts).
- **📱 Clean UI/UX:** Responsive, modern design with smooth animations and relaxing colors.

- **🎯 استكشاف المسارات المهنية:** التعرف على أهم مجالات سوق العمل التكنولوجي (تطوير الموبايل، الويب، اختبار البرمجيات، تحليل البيانات).
- **📋 قائمة مهام الخريج:** تنظيم وإدارة الأهداف اليومية مثل (مراجعة أساسيات Dart، بناء واجهات التطبيق، وغيرها).
- **📱 واجهة مستخدم عصرية:** تصميم متجاوب وألوان مريحة تزيد من طمأنينة المستخدم وتفاعله.

---

## 🛠️ Tech Stack | التقنيات المستخدمة

- **Framework:** [Flutter](https://flutter.dev)
- **Language:** [Dart](https://dart.dev)
- **State Management:** Stateful Widgets
- **Platform Support:** Android & iOS (Cross-Platform)

---

## 🚀 How to Run | طريقة التشغيل

You can easily run this project online via web editors without installation:
يمكنك تشغيل هذا المشروع فوراً أونلاين عبر المتصفح دون الحاجة لأي تثبيت:

1. Copy the code inside `main.dart`.
2. Go to [DartPad](https://dartpad.dev) or [FlutLab](https://flutlab.io).
3. Paste the code and click **Run**.
